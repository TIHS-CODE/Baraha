# Baraha
Download the .html file then run on your preferred browser or try it out on my website [here](https://tihs-code.neocities.org/Baraha)!

## What is it?
A single file to put card games I want to play on the go. I plan to make the site more customizable to really fit each player's preferences when playing these games.

## What card games are in it?
For now it's only [Pusoy Dos](https://en.wikipedia.org/wiki/Big_two): A card game where the entire deck is split between the players and they take turns dropping card/s that beat the previous card combo. First to run out of cards wins. Read more at the website.
